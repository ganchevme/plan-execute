# Changelog

Changes affecting settings or existing project plans will include migration guidance where needed. Released versions are not replaced; corrections receive a new version.

## 0.1.0 — 2026-11-16

Initial public release.

- Planning, execution and resumption through durable Markdown project records.
- Project templates, configurable execution preferences and a plan validator with regression tests.
- MIT license, installation and contribution guidance, and lightweight automated checks.
- Direct log capture by default, with optional integration for an independently installed log wrapper. No wrapper binaries or profiles are bundled.
